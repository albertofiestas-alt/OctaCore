# Ingreso conservador: P5, P20 y P50

La herramienta no supone el ingreso más probable. Calcula varios escenarios para el ingreso acumulado: P5 es una semana muy mala, P20 una semana mala, P50 una semana típica y P80 una semana buena.

Para el número de hoy se usa el escenario P20, es decir, un ingreso conservador. Así el número procura no depender de una semana buena. El escenario P5 se usa para revisar si una propuesta de apartar dinero protege el pago incluso en una semana muy mala.
